## 1. CEL I ZAKRES OPERACYJNY
Chirurgiczna redukcja archaicznego, mechanicznego syntezatora Web Speech API (`web`), permanentne wyeliminowanie drewnianych głosów przeglądarkowych oraz pełna integracja z Google Cloud Neural Text-to-Speech API (`google`) z darmowym pakietem 1 000 000 znaków miesięcznie (WaveNet i Neural2).

1. **Chirurgiczna Redukcja Web Speech API (`web`)**:
   - Trwałe usunięcie metody `speakWithWebSpeech` oraz tablicy `WEB_VOICE_PROFILES` ze wszystkich warstw aplikacji.
   - Usunięcie kafli i opcji konfiguracji głosu przeglądarkowego z `SettingsPage.jsx`.
   - Zabezpieczenie kaskady awaryjnej: w przypadku awarii zewnętrznych dostawców system nigdy nie odtwarza drewnianych głosów systemowych (np. Paulina Desktop), lecz emituje czyste powiadomienie `systemAlert`.
2. **Implementacja Google Cloud Neural Text-to-Speech API (`google`)**:
   - Bezpośrednie żądania REST do `https://texttospeech.googleapis.com/v1/text:synthesize?key=${apiKey}` z natywnym wsparciem CORS w przeglądarce.
   - Wsparcie bezpłatnego pakietu Free Tier (1 000 000 znaków miesięcznie bez wygasania).
   - Domyślny zestaw studyjnych lektorów polskich i angielskich `GOOGLE_DEFAULT_VOICES` (`pl-PL-Wavenet-B`, `pl-PL-Neural2-A`, `pl-PL-Wavenet-C`, `pl-PL-Wavenet-A`, `pl-PL-Wavenet-D`, `en-US-Journey-D`, `en-US-Neural2-F`).
   - Bezpieczne pole klucza API Google Cloud w Ustawieniach z przełącznikiem widoczności i selektorem lektorów.
   - Wsparcie backend proxy dla środowisk o ograniczonej łączności w `modules/routes/ai.js`, `api/tts.js` i `api/voice/tts.js`.

# Raport Wdrożenia: Optymalizacja Czułości Wake Word & Microsoft Edge Neural TTS (v2.18.0)

## 1. Zakres Zmian
- **Wysoka Czułość Wykrywania Wake Word ("Hej Omni") bez Konieczności Krzyczenia**:
  - Zidentyfikowano przyczynę słabej detekcji przy spokojnym i cichym głosie: silnik Google Web Speech API dla języka polskiego przy standardowej głośności mowy traktuje słowo „omni” jako rzadkie w leksykonie i podstawia fonetyczne odpowiedniki o wyższej frekwencji: „oni”, „o mnie”, „on mi”, „omnie”, „omnia”, „omi”, „homi”.
  - Rozszerzono wzorce detekcji `WAKE_WORD_PATTERNS` oraz mechanizm `extractWakeWordPayload` o pełną matrycę wariantów fonetycznych poprzedzonych dowolnym powitaniem („hej”, „ej”, „halo”, „siema”, „cześć”, „ok”, „witaj”, „yo”) oraz samodzielne wywołania („omni”, „omnie”, „omnia”, „omnik”).
  - Wdrożono analizę wielu hipotez rozpoznawania (`recognition.maxAlternatives = 5`), przeszukującą wszystkie alternatywy transkrypcji w zdarzeniu `onresult`.
  - Wyłączono agresywną programową bramkę szumów (`noiseSuppression: false`) w strumieniu mikrofonu `acquireSilentAudioStream()`, zapobiegając ucinaniu cichego lub szeptanego głosu.
  - Zabezpieczono procedurę `startLiveListeningLoop` w `Terminal.jsx` przed utratą cichej mowy przy zdarzeniu `onend` z transkrypcją częściową (`interimResults`).

- **Darmowa, Ultra-Realistyczna Synteza Mowy AI – Microsoft Edge Neural TTS**:
  - Zintegrowano silnik `msedge-tts` generujący studyjną jakość mowy (24kHz MP3) bez konieczności posiadania jakiegokolwiek klucza API, subskrypcji czy rejestracji kart.
  - Dodano dedykowane, naturalnie brzmiące głosy w języku polskim i angielskim:
    - `pl-PL-MarekNeural` (Męski - Studio Neural / Naturalny, czysty i wyrazisty)
    - `pl-PL-ZofiaNeural` (Damski - Studio Neural / Ciepły, płynny)
    - `pl-PL-AgnieszkaNeural` (Damski - Naturalny)
    - `en-US-ChristopherNeural` (Męski - Studio US English)
    - `en-US-JennyNeural` (Damski - Studio US English)
  - Silnik Microsoft Edge Neural został ustanowiony jako **główny i domyślny** w całym systemie (`ttsService.js`), z płynnym fallbackiem do lokalnego Web Speech API w razie braku sieci.

- **Obsługa w Backendzie i Serverless**:
  - Rozszerzono endpoint `POST /api/voice/tts` w `modules/routes/ai.js` o obsługę strumieniowania audio `msedge-tts` z buforowaniem i nagłówkami `audio/mpeg`.
  - Utworzono bezstanową funkcję brzegową `api/voice/tts.js` dla platformy Vercel.

- **Rozszerzenie Panelu Konfiguracji w Ustawieniach (`SettingsPage.jsx`)**:
  - Dodano 4-elementową siatkę wyboru silnika mowy: `Edge Neural (Polecany / Darmowy)`, `ElevenLabs (Hi-Fi)`, `OpenAI TTS (Studio)`, `Web Speech (Offline)`.
  - Wdrożono dedykowaną kartę konfiguracyjną Microsoft Edge Cognitive Neural API z listą wyboru głosów i oznaczeniem braku wymogu tokenów.

## 1. ZAKRES OPERACYJNY

Kompleksowa eliminacja defektów logicznych, wycieków zasobów i race conditions wykrytych przez audyt Senior Code Reviewera (Groq / GPT-OSS):

1. **Optymalizacja i Bezpieczeństwo Jądra Librus (`modules/services/gradeUtils.js`, `modules/services/librusService.js`, `api/librus.js`):**
   - Wyekstrahowano czysty moduł funkcyjny `modules/services/gradeUtils.js` z rygorystyczną walidacją wejścia (`toFiniteNumber` odrzuca typy boolean/symbole/obiekty, `isValidAverage`, `isNeutralGrade`, `getGradeWeight`, `getSubjectCode`, `getGradeBadgeStyle`).
   - W `api/librus.js` wprowadzono bezpieczny parser zakresu godzin `parseHourRange` eliminujący podatność na błędy parsowania nieregularnych znaczników czasu.
   - Usunięto niebezpieczną bezpośrednią mutację `process.env` przy zapisie poświadczeń w `POST /credentials`.
   - W `modules/services/librusService.js` dodano bezpieczne mapowanie semestru z fallbackiem, obsługę szczęśliwego numerka zachowującą wartość `0`, rygorystyczne filtrowanie wierszy tabeli HTML (`th > 0 && td > 0`) oraz deduplikację lekcji `addLessonIfUnique`.

2. **Audyt i Wzmocnienie Cyklu Życia `GradesPage.jsx`:**
   - Zastosowano hook `useSafeState` eliminujący próby aktualizacji stanu po odmontowaniu komponentu (Memory Leak Prevention).
   - Zintegrowano identyfikator żądania `requestIdRef` oraz `fetchAbortControllerRef` z bezwzględnym przerywaniem zapytań w toku przed inicjalizacją nowego pobierania.
   - Zagwarantowano bezwarunkowe czyszczenie subskrypcji Firestore `onSnapshot` w `unsubscribeRef` na poziomie odmontowania widoku.
   - Dodano bezpieczny system powiadomień `showToast` z automatycznym czyszczeniem timera `toastTimeoutRef` na unmount.
   - Wdrożono rygorystyczną walidację symulatora ocen (`ALLOWED_SIM_GRADES`, `ALLOWED_SIM_WEIGHTS`).

3. **Audyt i Wzmocnienie Osi Czasu `TimetablePage.jsx`:**
   - Wyeliminowano wycieki zapytań sieciowych: `abortCurrentRequest` wywoływane przed każdym nowym zapytaniem oraz podczas odmontowania komponentu z wyczyszczeniem referencji.
   - Wprowadzono sekwencyjne zarządzanie żądaniami przez `currentRequestIdRef` – zapobiega nadpisywaniu stanu przez opóźnione odpowiedzi HTTP.
   - Dodano zamrożoną mapę dni `DAY_MAP` na poziomie modułu oraz funkcję `mapDayToAbbrev` eliminującą fałszywe mapowania dni.
   - Odporne generowanie identyfikatorów `safeId` dla lekcji Librus.
   - Pełne zabezpieczenie asynchronicznych timerów `syncTimeoutRef` przed wyciekiem w pętli zdarzeń.

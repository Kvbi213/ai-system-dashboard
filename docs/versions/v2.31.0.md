## 1. ZAKRES OPERACYJNY
Wdrożenie kompletnego modułu **Entities & Intelligence OSINT Hub (v2.31.0)** łączącego drzewo hierarchiczne pochodzenia (Kraj -> Region -> Miasto -> Instytucja/Organizacja -> Osoba), graf relacji sieciowych, REST API Express, automatyczne geokodowanie, narzędzia agenta AI oraz interfejs użytkownika w stylu Glassmorphism:

1. **Model Danych SQLite WAL & Indeksy Drzewiaste (`modules/database.js`):**
   - Utworzono tabele `entities` (węzły hierarchii) oraz `entity_relations` (krawędzie grafu relacji).
   - Indeksy wydajnościowe: `idx_entities_parent`, `idx_entities_tree_path`, `idx_entities_type`, `idx_entities_name`, `idx_entity_relations_source`, `idx_entity_relations_target`.
   - Zapewniono obsługę asynchronicznej inicjalizacji i eksport metody `getDB()`.

2. **Silnik Drzewa i Geokodowania (`modules/services/entitiesService.js`):**
   - Pełna implementacja CRUD dla węzłów i relacji.
   - Algorytm `slugify` z normalizacją polskich znaków diakrytycznych.
   - Rekurencyjne wyliczanie `tree_path` oraz kaskadowa aktualizacja gałęzi potomnych przy zmianie rodzica lub nazwy.
   - Formatowanie drzewa ASCII dla terminala (`formatTreeAscii`).
   - Słowniki standaryzacji polskich województw i miast (`resolveLocationHierarchy`, `ensureLocationHierarchy`) z automatycznym łańcuchowaniem: Kraj -> Województwo -> Miasto.

3. **Interfejs API REST Express (`modules/routes/entities.js`, `core.server.js`):**
   - `GET /api/entities/tree` – pobieranie pełnego drzewa lub poddrzewa.
   - `GET /api/entities/ascii` – sformatowane drzewo tekstowe dla konsoli.
   - `GET /api/entities/stats` – statystyka liczby węzłów według typów.
   - `GET /api/entities/:id` – szczegóły pojedynczego podmiotu wraz z relacjami.
   - `POST /api/entities` – dodanie podmiotu z opcjonalnym auto-geokodowaniem `location_context`.
   - `PUT /api/entities/:id` – aktualizacja parametrów podmiotu.
   - `DELETE /api/entities/:id` – usunięcie podmiotu (opcja `cascade=true`).
   - `POST /api/entities/relations` – tworzenie krawędzi relacji sieciowej.
   - `DELETE /api/entities/relations/:id` – usunięcie relacji.

4. **Narzędzia Agenta AI & Zero-Trust Governance (`modules/ai/tools.js`, `modules/agent.js`):**
   - `ADD_TREE_ENTITY`: tworzenie węzłów z automatycznym podpinaniem pod kontekst lokalizacyjny.
   - `GET_ENTITY_TREE`: pobieranie struktury i poddrzew.
   - `SEARCH_PUBLIC_ENTITY`: wyszukiwanie informacji o podmiotach w sieci i bazie danych.
   - `LINK_ENTITIES`: tworzenie połączeń relacyjnych między podmiotami.

5. **Interfejs Użytkownika Glassmorphism (`EntityTreeView.jsx`, `EntityDetailsModal.jsx`, `OSINTPage.jsx`):**
   - Zakładki trybów: Drzewo Hierarchii, Terminal ASCII, Struktura JSON.
   - Wskaźniki statystyczne podmiotów: Total, `[COUNTRY]`, `[REGION]`, `[CITY]`, `[ORGANIZATION]`, `[PERSON]`.
   - Wyszukiwarka i filtr węzłów na żywo.
   - Modal szczegółów podmiotu z metadanymi, atrybutami, powiązaniami sieciowymi grafu oraz formularzem tworzenia relacji.
   - Integracja z `OSINTPage.jsx` umożliwiająca płynne przełączanie między wywiadem celu a bazą podmiotów.
   - Bezwzględna zgodność z regułą Zero-Emoji (wyłącznie znaczniki inżynieryjne).

6. **Pakiety Testów Automatycznych (`tests/entities_tree.test.js`, `tests/entities_hub.test.jsx`):**
   - 8 testów operacji bazodanowych i kalkulacji ścieżek (`entities_tree.test.js`).
   - 6 testów geokodowania, statystyk i renderowania komponentów UI (`entities_hub.test.jsx`).
   - Łączny bilans testów projektu: **235/235 PASS w 19 pakietach testowych (100% PASS)**.

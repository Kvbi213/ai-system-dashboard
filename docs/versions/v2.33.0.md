## 1. ZAKRES OPERACYJNY

Wdrozenie autonomicznego agenta sprzedazowo-prospektingowego Harvey opartego na pojedynczym kluczu Groq API (openai/gpt-oss-120b) oraz pelnej integracji silnika syntezy mowy Fish Audio (Ultra-Natural TTS & Voice Cloning):

1. **Harvey Sales & Outreach Persona (`modules/ai/harveyPersona.js`):**
   - Integracja zlozonych wzorcow sprzedazowych inspirowanych repozytorium `ethanplusai/harvey`.
   - 5 Ram Cold Email: AIDA, PAS, BAB, QVC, 3Ps.
   - 23 Sygnaly Zakupowe (SERP Rank, Agencja w stopce, Piksele reklamowe Meta/Google, brak bookingu online, porzucone blogi, rekrutacje).
   - Anti-AI Tells: Scisla eliminacja zargonu sztucznej inteligencji, zwiezle maile (50-110 slow), human-like CTA o niskim tarciu.
   - Procedura obslugi obiekcji LAARC (Listen, Acknowledge, Assess, Respond, Confirm).
   - Kwalifikacja BANT & MEDDIC oraz scoring ICP (1-10).

2. **Obsluga Trybu Harvey w Dyspozytorze i Bramie AI (`api/agent.js`, `clientAiDispatcher.js`):**
   - Zero dodatkowych kosztow tokenowych: pelne wykorzystanie istniejacego pojedynczego klucza Groq API (`VITE_GROQ_API_KEY` / `GROQ_API_KEY`).
   - Temperatura zoptymalizowana pod perswazyjnosc (0.5).
   - Dedykowane akcje systemowe: `[ACTION:HARVEY_PROSPECT]`, `[ACTION:HARVEY_CAMPAIGN]`, `[ACTION:HARVEY_QUALIFY]`.
   - Logowanie analitycznych przemyslen w dzienniku operacyjnym.

3. **Integracja Interfejsu Terminala i Kontekstu Chatu (`Terminal.jsx`, `ChatContext.jsx`):**
   - Nowy przelacznik trybu HARVEY w nawigacji z dedykowana ikona Briefcase.
   - Pelen cykl zycia historii chatu: `harveyMessages`, ladowanie, czyszczenie `/clear`, agresywny reset `/purge`, eksport `/export` oraz synchronizacja Cloud Firestore.
   - Autouzupelnianie polecenia `/mode harvey` w konsoli polecen.
   - Indykatory statusu glosowego na zywo dla trybu HARVEY.

4. **Obsluga Silnika Syntezy Mowy Fish Audio (`modules/services/ttsService.js`, `api/tts.js`, `modules/routes/ai.js`):**
   - Pelna integracja API `https://api.fish.audio/v1/tts`.
   - Domyslne modele glosowe: Anna, Michal, Piotr oraz obsluga wlasnego Reference ID (klonowanie glosu).
   - Transparentny fallback do Microsoft Edge Neural w razie braku klucza API, bledu sieciowego lub limitu.
   - Serverless proxy w `api/tts.js` oraz endpoint Express `/api/voice/tts`.

5. **Konfiguracja w Panelu Ustawien (`SettingsPage.jsx`):**
   - Nowa karta silnika syntezy "Fish Audio (AUDIO-AI)" w siatce wyboru TTS.
   - Konfigurator klucza API z przelacznikiem widocznosci hasla.
   - Wybor lektora referencyjnego oraz pole wlasnego ID modelu.
   - Przycisk testu glosu na zywo.

6. **Nowe Pakiety Testowe:**

# Raport Wdrożenia: Studyjna Synteza Mowy ElevenLabs & Manualne Wyciszanie Mikrofonu (v2.18.6)

## 1. Zakres Zmian
- **Integracja Studyjnej Syntezy Mowy ElevenLabs (TTS Engine)**:
  - Podłączenie oficjalnego silnika ElevenLabs API z modelem `eleven_multilingual_v2` dedykowanym dla języka polskiego.
  - Zarejestrowanie głosów studyjnych:
    - `Adam` (`pNInz6obpgDQGcFmaJgB`) — studyjny głos męski, głęboki i wyrazisty.
    - `Antoni` (`ErXwobaYiN019PkySvjV`) — naturalny polski lektor, spokojny i zrównoważony.
    - `Rachel` (`21m00Tcm4TlvDq8ikWAM`) — czysty i precyzyjny głos żeński.
    - `Sarah` (`EXAVITQu4vr4xnSDxMaL`) — dynamiczny głos asystencki.
  - Automatyczna hierarchia źródeł poświadczeń: `localStorage` -> zmienna środowiskowa `VITE_ELEVENLABS_API_KEY` -> zmienna `ELEVENLABS_API_KEY` w backendzie proxy.
  - Automatyczny wybór silnika: obecność klucza ElevenLabs automatycznie ustawia go jako preferowany silnik syntezy z kaskadowym przełączaniem awaryjnym (*multi-tier fallback*): `elevenlabs` -> `edge` (Microsoft Neural) -> `web` (Web Speech API).
- **Manualne Wyciszanie Mikrofonu (Hardware & Loop Mute Toggle)**:
  - **Przycisk w Trybie Ciągłej Rozmowy (`LiveVoiceBar` w Terminalu)**:
    - Dodano przycisk `[Wycisz] / [Odcisz]` z dedykowanymi ikonami `<MicOff />` i `<Mic />`.
    - Wyciszenie natychmiastowo przerywa instancję `SpeechRecognition` (`.abort()`), unieważnia callbacki, kasuje timery VAD oraz blokuje pętlę wznawiania nasłuchu.
    - Wizualny wskaźnik stanu: bursztynowy badge `[WYCISZONY (MANUALNIE)]`, ikona `<MicOff className="text-amber-400" />` oraz dedykowany komunikat statusowy.
  - **Przycisk w Pasku Wprowadzania Wiadomości (Standard Chat Toolbar)**:
    - Dodano dedykowany okrągły przycisk wyciszania/odciszania mikrofonu z ikoną `<MicOff />` / `<Mic />` obok przycisku trybu ciągłego (`Radio`) i dyktafonu.
    - Przełącza globalny stan nasłuchu w `wakeWordService` (`toggleMute()`), uniemożliwiając samoczynne wybudzanie asystenta frazą „Hej Omni”.
  - **Przycisk w Pływającym Inspektorze Diagnostycznym (`VoiceInspectorHUD`)**:
    - Dodano pełnowymiarowy przycisk `WYCISZ MIKROFON (MUTE)` / `ODCISZ MIKROFON (KLIKNIJ)` zintegrowany z magistralą zdarzeń systemowych `omniMicMuteChanged`.
- **Synchronizacja Konfiguracji Środowiskowej**:
  - Zaktualizowano `.env` oraz `.env.example` o parametry `ELEVENLABS_API_KEY` oraz `VITE_ELEVENLABS_API_KEY`.
  - W `SettingsPage.jsx` zaimplementowano automatyczne wczytywanie klucza ze zmiennych środowiskowych i automatyczne ustawienie silnika ElevenLabs jako domyślnego.

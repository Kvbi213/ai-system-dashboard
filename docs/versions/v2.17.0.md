# Raport Wdrożenia: Natywny Live Voice Chat & Wielosilnikowe TTS (v2.17.0)

## 1. Zakres Zmian
- **Natywna Integracja Wake Word z Czatem (`/chat`)**: Wywołanie słowa kluczowego "Hej Omni" (lub wariantów "Omni", "Hej Omni") w dowolnym miejscu aplikacji powoduje natychmiastową nawigację do głównego widoku czatu (`/chat`) za pośrednictwem `GlobalEventListener.jsx` i automatyczną aktywację trybu ciągłej rozmowy głosowej.
- **Wbudowany Pasek Głosu Live (Live Voice Bar w `Terminal.jsx`)**: Zastąpiono oderwany, pełnoekranowy modal z kulą radarową zintegrowanym, nowoczesnym paskiem stanu głosu w głównym terminalu rozmowy. Wiadomości, wykresy i widżety generowane w trakcie rozmowy głosowej są natychmiast rejestrowane w historii wątku czatu i stale widoczne dla operatora.
- **Chirurgiczna Redukcja `GlobalLiveVoiceModal.jsx`**: Na bezpośrednie polecenie operatora usunięto przestarzały komponent modalu kuli radarowej, redukując redundancję kodu i zapewniając jednolity interfejs konwersacyjny.
- **Wielosilnikowa Synteza Mowy (Multi-Engine Neural TTS - `ttsService.js`)**:
  - **ElevenLabs Multilingual v2**: Obsługa hiperrealistycznych głosów neuronowych (`Adam`, `Antoni`, `Rachel`, `Nicole`, `Arnold`) z konfiguracją klucza API w Ustawieniach lub `.env`.
  - **OpenAI TTS-1**: Obsługa modeli mowy OpenAI (`alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`).
  - **Web Speech Neural Fallback**: Inteligentne priorytetyzowanie naturalnych głosów przeglądarkowych (`Microsoft Paulina Online (Natural)`, `Microsoft Marek Online (Natural)`, `Google polski`).
  - Bezpośredni streaming audio przez `AudioContext` z precyzyjną kontrolą cyklu życia (`_isSpeaking`, `onStart`, `onEnd`, `onError`) oraz buforem akustycznym (400ms) zapobiegającym pętli sprzężenia zwrotnego.
- **Backend TTS Proxy (`/api/voice/tts` w `modules/routes/ai.js`)**: Bezpieczny punkt końcowy proxy dla zapytań ElevenLabs i OpenAI TTS ze wsparciem dla kluczy środowiskowych serwera oraz nagłówków autoryzacyjnych klienta.
- **Panel Konfiguracji Głosu w Ustawieniach (`SettingsPage.jsx`)**: Pełna konfiguracja silnika syntezy, wyboru głosu, wprowadzania kluczy API oraz dedykowany przycisk inicjujący testowy Live Voice Chat w terminalu.

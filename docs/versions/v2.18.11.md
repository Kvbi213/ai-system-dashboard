## 1. Zakres Zmian

### `[+]` Nowe Funkcjonalności i Ulepszenia
- **Wysokiej Czytelności Format Wiersza Lekcji (`• HH:MM [Sala] Przedmiot (Nauczyciel)`):**
  - Przeniesienie numeru sali `[Sala 1.16]` / `[Hala]` na początek wiersza (bezpośrednio po godzinie), eliminujące konieczność szukania sali na końcu długiej, zawiniętej linii.
  - Słownik standaryzacji nazw (`cleanSubjectName`) automatycznie skracający wielowyrazowe nazwy przedmiotów:
    - `Pracownia urządzeń techniki komputerowej` -> `Pracownia UTK`
    - `Pracownia systemów operacyjnych` -> `Pracownia SO`
    - `Wychowanie fizyczne` -> `WF`
    - `Zajęcia z wychowawcą` -> `Godz. wychowawcza`
    - `Urządzenia techniki komputerowej` -> `Urządzenia TK`
  - Usunięcie zbędnego szumu informacyjnego (metadane typu `, Laboratorium`, `, Wykład`, `, Ćwiczenia`, `, Inne`).
  - Poprawiona ekstrakcja inicjałów nauczycieli z uwzględnieniem polskich znaków diakrytycznych (`GŁ`, `ZJ`, itp.).
- **Uniwersalne Objęcie Wszystkich Ścieżek Formaterem `formatPushText`:**
  - `modules/pushbullet.js`: backendowa funkcja `sendPushNotification` automatycznie normalizuje treść przed wysyłką do Pushbullet API.
  - `api/phone.js`: serverless handler automatycznie formatuje przekazywane `body`.
  - `api/agent.js` oraz `modules/services/clientAiDispatcher.js`: zoptymalizowano `timetableSummary` w prompcie LLM, dzięki czemu model otrzymuje i generuje już wyłącznie zwięzłe, jednoznaczne wpisy.
- **Rozszerzenie Zestawu Testów Jednostkowych (`tests/pushbullet_finance.test.js`):**
  - Dodano dedykowany test weryfikujący wyodrębnianie sali, nauczyciela i czyszczenie nazw przedmiotów z formatu surowego (83/83 PASS).

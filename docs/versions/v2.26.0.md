### 2. PROTOKÓŁ ARCHITEKTURY GOOGLE CLOUD PUB/SUB & BILLING

1. **Identyfikator Projektu:** `void-potato-7721` (Void Potato Matrix / europe-central2).
2. **Temat Pub/Sub:** `projects/void-potato-7721/topics/omni-budget-alerts`
3. **Subskrypcja Push:** `projects/void-potato-7721/subscriptions/omni-budget-push`
4. **Punkt Końcowy Webhook:** `https://void-potato-7721.web.app/api/gcp/budget-webhook`
5. **Polityka Reagowania na Koszty:**
   - 50% budżetu: Status OK [INFO].
   - 80% budżetu: Status WARNING [WARN].
   - 90% budżetu: Status WARNING -> Natychmiastowe wysłanie alertu Pushbullet na smartfon operatora.
   - 100% budżetu: Status CRITICAL -> Aktywacja flagi `isBudgetThrottled = true` i krytyczny alert na telefon.
